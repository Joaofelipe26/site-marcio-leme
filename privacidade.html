Política de privacidade

Última atualização: 22 de outubro de 2026.

Quem é o responsável

Este site pertence a Márcio Leme de Almeida, advogado inscrito na OAB/SP sob nº 250.781, com escritórios em São Paulo/SP e Itapetininga/SP. Para assuntos de privacidade, use o e-mail marcio.leme@adv.oabsp.org.br.

Quais dados este site coleta

Este site não tem formulários, não usa cookies e não usa ferramentas de análise de visitas ou de publicidade. As fontes, as imagens e os mapas ficam no próprio site. Nenhum conteúdo é carregado de serviços de terceiros durante a visita.

Hospedagem

O site é hospedado pelo GitHub Pages (GitHub, Inc.). Como qualquer servidor, o GitHub pode registrar dados técnicos de acesso, como o endereço IP, para fins de segurança e funcionamento do serviço. Esse tratamento segue a política de privacidade do GitHub.

Links para outros serviços

Os botões de WhatsApp, e-mail e "Ir até lá" (Google Maps) só abrem esses serviços quando você clica neles. A partir desse momento, valem as políticas de privacidade de cada serviço.

Contato com o escritório

Quando você entra em contato por WhatsApp ou e-mail, as informações enviadas são usadas somente para responder e para prestar o atendimento jurídico. Elas são protegidas pelo sigilo profissional da advocacia e não são compartilhadas com terceiros, exceto quando a lei exigir.

Seus direitos

Pela Lei Geral de Proteção de Dados (Lei nº 13.709/2018), você pode pedir a confirmação do tratamento, o acesso, a correção ou a exclusão dos seus dados pessoais. Para isso, envie um e-mail para o endereço acima.
